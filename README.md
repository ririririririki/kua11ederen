# GitHub 发布版作品集

本目录来自你提供的完整 HTML，保留 27 个项目、14 个分组、209 张项目图片和 13 个项目视频。背景按要求改为纯白。

## 上传到 GitHub

1. 先解压 ZIP。上传目录里面的 index.html、assets 文件夹、.nojekyll 和其他文件，保持相对位置。不要把 ZIP 本身当成网站上传。
2. 推荐使用 GitHub Desktop：将这些文件复制进仓库本地目录，提交并 Push。网页手动上传也可以，但素材较多，请分批上传并保留 assets 内的目录结构。
3. 仓库 Settings → Pages → Deploy from a branch，选择 main 分支和 /(root)，保存。
4. 等待 Pages 部署完成，使用 GitHub 给出的网页地址查看。

所有发布文件均小于 25 MiB；站点总量小于 1 GB。无需 Git LFS。

## 本地预览与编辑

直接打开 index.html 可浏览页面；请始终保持 assets 文件夹与它一起。

也可以通过本地预览服务编辑和导出完整独立 HTML，在此目录运行：

    node preview.cjs

然后打开终端显示的 http://127.0.0.1 地址。Node.js 未安装时，也可以先上传 GitHub Pages 后，在网站地址下编辑和导出。使用完本地预览后按 Ctrl+C 关闭。

页面内“保存”只保存在当前浏览器，不会直接修改 GitHub 仓库。修改完成后下载最新 HTML，重新整理发布目录再更新仓库。原始完整 HTML 是你的原画质编辑备份，请继续保留。

## 压缩方式

- 图片：WebP，质量 90，长边最多 2560 像素，不放大小图。
- 视频：已满足网页规格的保留原画面编码并优化封装；其余转换 H.264、AAC，长边最多 1280 像素，最高 30fps，开启 Fast Start。
- 发布副本经过有损压缩，原始 HTML 和原素材未修改。
- 原文件引用的失效背景视频已按要求移除，背景为纯白。一个未启用的旧 Logo 引用也已清理，当前页眉文字和链接保留。

## 本地布局与全景编辑

双击「启动本地编辑.cmd」会启动本地预览并打开浏览器；需要已安装 Node.js，使用时保持服务窗口打开。全景建议在该入口编辑和验证；直接双击 index.html 时，本地图片因浏览器安全限制以普通图片显示。真机陀螺仪请在 HTTPS 页面验证，iOS 首次需点击页面授权。

注意：本地服务网址和 file:// 直接打开使用各自的浏览器草稿缓存，不会自动互相迁移。已有草稿请保留原入口；本次升级没有改变保存到浏览器的机制，也没有增加写回仓库功能。


## 主頁視頻順序與圖片幻燈片

主頁視頻隨下滑按先上排、後下排、同排從左到右逐個交接。停止滑動時保持當前視頻；上滑反向切換；快速滑動越過屏外內容時只播放當前可見視頻。全頁同時只播放一個視頻，正式頁不顯示播放器控件。

在「項目內容」的編組設定中，勾選「圖片幻燈片 · 向左無縫滑動」，可獨立選擇 0.5、1、2、3、4、5 秒，默認 3 秒。僅支持至少兩張圖片的純圖片編組，視頻或混合編組不輪播。普通編組保留點擊查看；全寬固定編組只預覽、不可點擊。

輪播預先解碼下一張，再以約 0.35 秒從右向左連續滑動，前後圖片緊貼、無空隙。每張停留時間按所選秒數計算，滑動過渡另計；下一張未準備好時維持當前圖片，錯誤圖片跳過。普通卡片維持原格子尺寸，全寬固定輪播以首張圖片比例固定高度，後續圖片鋪滿裁切。編輯畫布靜止，使用預覽和正式頁僅在可見區域輪播；打開詳情或離開頁面時暫停。圖片輪播與全景模式分別使用，啟用輪播後不啟用同一項目的全景。

保存仍沿用瀏覽器草稿機制；本輪沒有增加寫回網站文件夾或自動推送功能。


## 直接雙擊本地 HTML 後下載最新備份

直接雙擊 index.html 後，可以在原入口編輯、保存並下載完整 HTML。點擊「下載最新 HTML」時，按提示選擇含 index.html 和 assets 的網站根文件夾（例如 文檔/GitHub/kua11ederen），不要只選 assets。瀏覽器僅需讀取權限，會把磁盤中的既有素材與當前瀏覽器已保存的修改、新上傳素材一起打包；不覆蓋源文件，也不清理草稿。

所選文件夾不正確、素材缺失或取消選擇時會顯示相應提示，已保存草稿仍保留。通過 HTTP/HTTPS 網址打開時，原有直接導出方式保持不變。完整離線備份已內嵌素材，再次導出時不需要選取素材文件夾。下載備份仍是大體積離線文件，GitHub 發布繼續使用網頁與 assets 分離的倉庫版本。


## 固定項目之間的網格補位與查看層頂部

主頁切換 1–5 列時，後面的普通項目可以跨過全寬固定項目，填補前面未滿行的空格。固定項目仍全寬獨占一行；保存的項目順序不變，視頻按補位後實際顯示位置順序播放。編輯畫布、使用預覽和正式頁使用相同補位佈局。

查看編組及單張項目時，內容視窗從頂部欄下方開始，按頂部欄實際高度加 8 像素留出空間，適應橫豎屏和欄高變化。此次只調整布局，打開、返回和滾動流程沿用原有行為。
